# GRe Toolkit Template Manual

This manual records the workbook templates embedded in the BERT/GRe toolkit and
the behavior expected from their `Gather`, `Update`, and `Build` actions.

## Template: China Exposure Mapping

Workbook:

```text
excel/templates/Template_China_Exposure_Mapping.xlsm
```

Objective marker:

```text
<exposure map>
```

Place the objective marker in `A1` of the active worksheet used to run the
template. The current template uses the `Parameters` sheet as the main control
surface.

### Ribbon Actions

`Gather`

Currently unsupported. Reserved for a future workflow that collects or reshapes
source data from other workbook tabs into the `Input_Data` sheet.

`Update`

Runs the China exposure map calculation through BERT/R, overwrites the workbook
local output folder, and refreshes the embedded workbook plot objects.

Output folder:

```text
<workbook folder>\_BERTToolkitTemp\china_exposure_map\
```

Embedded images:

```text
plot_EQ_yoy.png -> Parameters!N17
plot_WS_yoy.png -> Parameters!N50
```

`Build`

Currently unsupported for this template. The files generated by `Update` are
already available for external use in the workbook-local output folder.

Generated files from `Update`:

```text
plot_EQ.png
plot_WS.png
plot_EQ_yoy.png
plot_WS_yoy.png
plot_EQ_combined.png
plot_WS_combined.png
plot_EQ_cropped.png
plot_WS_cropped.png
```

```text

```

### VBA Packaging

The workbook contains the custom ribbon XML. To embed or refresh the VBA module
inside the Windows VM, run:

```text
C:\CompanyTools\BERTToolkit\excel\scripts\embed_vba.vbs
```

Excel must allow programmatic VBA project access:

```text
File > Options > Trust Center > Trust Center Settings > Macro Settings >
Trust access to the VBA project object model
```

```text
excel/templates/Template_XOL_Pricing_Tool.xlsm
```

Source workbook:

```text
XL Pricing Templates/XL Pricing Template.xlsm
```

Tool ID:

```text
xl_pricing_tool
```

Objective markers:

```text
<xl pricing>
<xl pricing tool>
<xol pricing>
```

The objective marker should be placed in `A1` of the active worksheet used to
run the GRe ribbon actions. The workbook shell is otherwise intended to preserve
the source XL pricing template until tab-level actions are explicitly defined.

### Ribbon Actions

`Gather`

Registered for `xl_pricing_tool`, but tab-level behavior is pending. Expected
future role: collect and reshape source data into the workbook input tabs.

`Update`

Registered for `xl_pricing_tool`, but tab-level behavior is pending. Expected
future role: refresh derived data, R-side calculations, and workbook-visible
outputs that are defined in the tab contract.

`Build`

Registered for `xl_pricing_tool`, but tab-level behavior is pending. Expected
future role: produce final pricing deliverables or export artifacts.

### Packaging Notes

The GRe ribbon XML can be embedded into the workbook package directly. The
shared VBA module should be embedded from the Windows VM with:


### Tab: Input_GNPI

Marker:

```text
<<GNPI>>
```

`Gather`

Not defined by default because `Gather From` is blank. The expected message is:

```text
No gather action defined for Input_GNPI because Gather From is blank.
```

`Update`

Reads the dynamic GNPI input table starting at `B12:I`. Required headers are:

```text
LOB
TreatyYear
Type
GNPI_Original
Adjustment
GNPI
Latest_Current
Latest_Prior
```

The action uses `Input_GNPI!L19` as the chart start year and `Input_GNPI!L41`
downward as the LOB display sequence.

Generated files:

```text
<workbook folder>\_BERTToolkitTemp\xl_pricing_tool\gnpi\gnpi_level_data.csv
<workbook folder>\_BERTToolkitTemp\xl_pricing_tool\gnpi\gnpi_lob_comparison_data.csv
<workbook folder>\_BERTToolkitTemp\xl_pricing_tool\gnpi\gnpi_chart_config.csv
```

The first output supports a stacked native Excel chart showing total GNPI by
year across all LOBs, split by `Actual`, `Revised`, and `Estimate`, with flags
for latest prior year and latest current year. The second output supports a
native Excel clustered comparison of `Latest_Prior` and `Latest_Current` by LOB.

`Build`

No standalone build output is defined for this tab.

Broken workbook names `Anchor_RDataspec` and `Anchor_ROutput` are not used for
this tab. If anchors are needed later, create explicit GNPI-specific names
instead of reusing those stale `#REF!` names.
